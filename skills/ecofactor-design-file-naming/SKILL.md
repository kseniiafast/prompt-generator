# ECOFACTOR Design: як називати файли

Ці правила діють для **дизайнерських файлів**: анімацій, титрів, графіки, відео, звуку, макетів і презентацій, які робить дизайн-команда.
На робочі документи інших відділів (договори, звіти, таблиці) вони не поширюються.

Кожен файл, який користувач скачає, має одразу називатися правильно.
Не можна віддавати файли з назвами `animation.html`, `output.mp4`, `index.html`, `captions.srt`, `untitled` тощо.

## Шаблон

```
EF_<проєкт>_<тип>_<назва>[_<формат>][_<мова>]_v<NN>.<розширення>
```

| Поле | Обовʼязкове | Що це | Приклади |
|---|---|---|---|
| `EF` | так | префікс бренду, завжди `EF` | `EF` |
| `<проєкт>` | так | назва чату або проєкту | `ECO-Totem`, `Summer-Promo` |
| `<тип>` | так | тип файлу, зі списку нижче | `anim`, `cap` |
| `<назва>` | так | що саме в файлі | `intro`, `outro`, `title` |
| `<формат>` | якщо є кілька форматів | співвідношення сторін | `9x16`, `16x9`, `1x1`, `4x5` |
| `<мова>` | якщо є кілька мов | код мови | `UA`, `EN` |
| `v<NN>` | так | версія, завжди дві цифри | `v01`, `v02`, `v12` |

### Роздільники та символи

- `_` (нижнє підкреслення) ставиться **тільки між полями**.
- `-` (дефіс) ставиться **всередині поля**, якщо поле з кількох слів: `ECO-Totem`, `lower-third`.
- Тільки латиниця, цифри, `_` та `-`. Без пробілів, кирилиці, крапок (крім розширення), дужок і `&`.
- Кириличну назву проєкту треба транслітерувати: «Тотем» → `Totem`.
- Регістр полів:
  - `EF` та `<мова>` пишуться великими літерами;
  - `<тип>`, `<назва>` та `<формат>` пишуться малими;
  - `<проєкт>` пишеться так, як його дав користувач, але з дефісами замість пробілів і `_` (наприклад, `ECO_Totem` → `ECO-Totem`).

## Типи (`<тип>`)

| Код | Що це |
|---|---|
| `anim` | анімація (HTML, GIF, MP4, MOV, WebM, Lottie) |
| `cap` | титри, субтитри, captions (SRT, VTT, TXT) |
| `img` | статичне зображення (PNG, JPG, SVG) |
| `vid` | відео без анімаційної графіки, монтаж |
| `sfx` | звук або музика |
| `doc` | документ |
| `deck` | презентація |

Якщо файл не підходить під жоден тип, спитай у користувача і не вигадуй новий код мовчки.

## Назви (`<назва>`)

Часті значення: `intro`, `outro`, `title`, `lower-third` (плашка з іменем), `cta` (заклик до дії), `logo`, `transition`, `loop`, `bg` (фон), `full` (повна версія ролика).
Якщо в одному типі кілька однакових елементів, додай номер через дефіс: `title-01`, `title-02`.

## Звідки брати `<проєкт>`

1. Якщо користувач назвав проєкт або чат (наприклад, «ECO Totem»), бери цю назву.
2. Якщо назви ще немає, **перед першим файлом коротко спитай**: «Як назвати проєкт у назвах файлів? Наприклад, `ECO-Totem`». Далі використовуй цю назву в усьому чаті й не питай знову.

## Версії

- Перший файл має версію `v01`.
- Кожна нова правка того самого файлу піднімає версію: `v02`, `v03`… Це потрібно, щоб браузер не додавав `(1)`, `(2)` до однакових назв і щоб було видно, яка версія остання.
- Якщо файл той самий, але в іншому форматі чи розширенні (MP4 і MOV з прозорістю), версія лишається та сама, змінюється тільки розширення.

## Як застосовувати

- **Файл, який ти створюєш і віддаєш** (MP4, GIF, SRT, HTML…), одразу збережи під правильною назвою.
- **Кнопка «скачати» всередині артефакту чи HTML-сторінки** повинна мати атрибут `download` з правильною назвою:
  ```html
  <a href="..." download="EF_ECO-Totem_anim_intro_9x16_v01.mp4">Скачати</a>
  ```
  А якщо файл генерується в JS (canvas, MediaRecorder, Blob):
  ```js
  a.download = 'EF_ECO-Totem_anim_intro_9x16_v01.webm';
  ```
- **Набір файлів**: кожен файл називається за шаблоном. Якщо їх багато, запропонуй ZIP з назвою `EF_<проєкт>_<тип>_pack_v<NN>.zip`.
- Після створення файлу **покажи його назву у відповіді**, щоб користувач бачив, що вона правильна.

## Неправильно → правильно

| Неправильно | Чому | Правильно |
|---|---|---|
| `animation.mp4` | немає жодного поля | `EF_ECO-Totem_anim_intro_v01.mp4` |
| `EF_ECO_Totem_anim_intro.mp4` | `_` всередині назви проєкту ламає поля; немає версії | `EF_ECO-Totem_anim_intro_v01.mp4` |
| `EF ECO Totem anim intro v1.mp4` | пробіли; версія з однієї цифри | `EF_ECO-Totem_anim_intro_v01.mp4` |
| `EF_Тотем_anim_інтро_v01.mp4` | кирилиця | `EF_Totem_anim_intro_v01.mp4` |
| `EF_ECO-Totem_Anim_Intro_v01.mp4` | тип і назва великими літерами | `EF_ECO-Totem_anim_intro_v01.mp4` |
